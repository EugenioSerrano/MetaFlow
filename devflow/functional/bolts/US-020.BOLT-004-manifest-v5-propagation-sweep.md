## 1. Description

BOLT-001 shipped the v5 schemas and BOLT-002 aligned the core manifest
description, but the **reference/template tier** of the kit still describes the
manifest as v4: the manifest reference document (`metrics/README.md`), several
artifact templates and the per-folder READMEs, plus the §3.12 embedded example.
This Bolt finishes propagating the v5 manifest change across that tier so the kit
is internally consistent and the shipped example validates against the shipped
schema. Discovered during US-020.BOLT-003's AC-3 sweep (rev-2 finding).

---

## 2. Expected outcome and completion evidence

- **Objective:** every place in the kit that *describes* the manifest speaks v5,
  and the reference example is valid against the v5 schema an adopter would run.
- **Completion criterion — three outcome buckets:**
  - **(A) Array rename** — no prose describing the *current* manifest still calls
    the approval array `hitl_approvals[]`; it reads `checkpoint_approvals[]`
    (the v4-source references inside the §5.16 conversion recipe and the four
    agents' upgrade notes legitimately keep the v4 name and are the allowlist).
  - **(B) Approver reshape** — the §3.12 embedded example manifest and the
    reference approver prose show the v5 shape (`{actor, role, model}` + entry
    `mode`), and the example **validates GREEN** against the v5 schema. The
    artifact-level `review.reviewers[].user` contract stays `{user, role}` (the
    `user`→`actor` projection happens only at the manifest boundary) and is
    **not** changed.
  - **(C) Schema references** — no document links to a deleted
    `manifest-v4-*.schema.json`; the reference/template docs name the v5 schema
    files, and the "Schema family v4" / `schema_version "4.0"` labels read v5
    (the §5.16 recipe keeps `"4.0"` where it names the v4 source being converted).
- **Expected evidence:** the ADR-005 phrase-family sweep (fixed location set +
  allowlist) is clean; the §3.12 example validates against BOLT-001's v5 schema;
  `git status` shows only `distribution-kit/`; four-agent sync + G-count intact
  if any agent file is touched.
- **Scope:** the kit's manifest *documentation* tier — `metrics/README.md`, the
  artifact templates that reference the manifest, the per-folder READMEs, and the
  §3.12 embedded example.
- **Exclusions:** the v5 schemas/templates JSON (BOLT-001, Done); the core §3.12
  structure prose + §5.16 recipe (BOLT-002/003, Done); the `HITL-*`→`AITL-*`
  checkpoint rename (separate US); the root `devflow/` (ADR-004); converting this
  repo's actual manifests (a future §5.16 event).
- **Risks / controls:** an incomplete sweep leaves a mixed v4/v5 kit — control:
  the ADR-005 phrase-family AC over a declared location set with an explicit
  allowlist, phrased as an absence; over-reach that changes the artifact-level
  `review.reviewers` contract — control: (B) explicitly excludes it.
