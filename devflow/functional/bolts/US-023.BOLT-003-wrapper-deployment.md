---

## 1. Description

The per-platform wrappers for the canonical DevFlow Agents (BOLT-001
definitions) are **generated with the BOLT-002 generator and committed**
into the kit — `.claude/agents/*.md`, `.opencode/agents/*.md`,
`.github/agents/*.agent.md`, `.codex/agents/*.toml` — together with
**per-platform verification notes**: Claude Code receives full native
coverage (model + tools + MCP + hooks + allowlists); Codex (open invocation
issues #14579/#15250) and Copilot (env-dependent `model` / `mcp-servers`)
are **re-verified against current docs** at implementation and use
documented fallbacks (DISC-002 rec #6, §7 #1). Adopters run no build step —
the wrappers ship pre-built.

---

## 2. Expected outcome and completion evidence

- **Objective:** every platform's wrapper folder in the kit carries the
  deployed projections of the canonical agents, with honest per-platform
  capability notes.
- **Completion criterion:** the four wrapper locations exist with the
  generated files; the parity check (BOLT-002) passes over the committed
  set; the verification notes record the Claude full-coverage claim and the
  Codex/Copilot re-verification + fallbacks.
- **Expected evidence:** the committed wrapper trees; the parity result;
  the verification notes (per platform).
- **Scope:** the kit's platform agent folders + the verification notes.
- **Exclusions:** the generator itself (BOLT-002); the smoke test
  (BOLT-004); the root `devflow/` (ADR-004).
- **Risks / controls:** platform contract drift — controlled by the
  re-verification at implementation (DISC-002 rec #6) and the parity gate.

---

## 3. Covered acceptance criteria

> Reference the ACs of the parent artifact — never write new ones here
> (§2.4, §2.6).

- `AC-6` (US-023) — **Given** spawn topology, **When** executors run,
  **Then** approver agents are spawnable only by the Coordinator — the
  **deployed per-platform wrappers set the spawn allowlists** that enforce
  it (Claude Code `Agent(...)` allowlist, OpenCode `permission.task`,
  Copilot tool omission, Codex role config + parent instruction); BOLT-004
  confirms the topology at smoke level.
- `AC-9` (US-023) — **Given** the wrapper generator, **When** canonical
  definitions change, **Then** per-platform wrappers are generated and
  **committed** to the kit and the **N×4 parity check** passes; adopters
  run **no build step**.
- `AC-10` (US-023) — **Given** the platform verification status, **When**
  wrappers are generated, **Then** Claude Code receives full native
  coverage; Codex and Copilot are **re-verified against current docs** and
  use documented fallbacks, recorded per platform.
- `AC-11` (US-023) — **Given** the kit partition, **When** this Bolt lands,
  **Then** only `distribution-kit/` changes.
