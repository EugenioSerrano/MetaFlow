---

## 1. Description

A **minimal spawn smoke test** on the pilot platform (Claude Code — the
only platform with full native coverage: model + tools + MCP + hooks +
spawn allowlists, DISC-002 §5.6): the deployed wrapper files (BOLT-003)
load; a role agent spawns with its declared model/tools; the agent
**takes the baton and produces a trivial artifact of its role** (executor
side of the Actor, AC-3); control returns to the parent via the spawn
result. This is the first Bolt's smoke evidence called for by DISC-002 §7
#7 — the full flow + red-team pilot remains a separate, later US.

---

## 2. Expected outcome and completion evidence

- **Objective:** proof that the deployed wrappers are loadable and spawnable
  on the pilot platform, with the producer mechanics working and control
  returning — before the full pilot US.
- **Completion criterion:** the smoke test runs successfully: wrapper loads;
  role agent spawns with its declared model/tools; a trivial role artifact
  is produced; control returns to the parent.
- **Expected evidence:** the smoke test script/run + its result (spawn
  outcome, produced artifact, control-return note).
- **Scope:** the smoke test on the pilot platform (Claude Code) + its
  recorded evidence.
- **Exclusions:** the full pilot flow + red-team AC (later US); the other
  three platforms' smoke (their wrappers are verified via parity + notes in
  BOLT-003); the root `devflow/` (ADR-004).
- **Risks / controls:** platform behavior differs from docs — controlled by
  recording the actual behavior in the evidence and the pilot US's
  re-verification (DISC-002 §7 #1).

---

## 3. Covered acceptance criteria

> Reference the ACs of the parent artifact — never write new ones here
> (§2.4, §2.6).

- `AC-3` (US-023) — **Given** a role agent spawned by the Coordinator for a
  V-Bounce, **When** the flow executes, **Then** the agent takes the baton
  and produces its role's artifacts inside the approved flow, returning
  control via the spawn result (state = files) — proven at smoke level.
- `AC-6` (US-023) — **Given** spawn topology, **When** executors run,
  **Then** approver agents are spawnable only by the Coordinator — the
  smoke test exercises an executor spawn and **confirms** the topology
  holds on the pilot platform (the enforcement itself is encoded in the
  BOLT-001 charters and the BOLT-003 deployed wrappers).
- `AC-11` (US-023) — **Given** the kit partition, **When** this Bolt lands,
  **Then** only `distribution-kit/` changes.
