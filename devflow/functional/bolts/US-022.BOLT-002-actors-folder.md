---

## 1. Description

The kit gains the `devflow/actors/` folder (G30-sanctioned by US-022) with
a README that teaches the Actor concept, hosts the roster (the schema +
example land in US-024) and disambiguates `actors/` (who is in the team)
from `agents/` (the AI-member definitions, US-023) on its first line.

---

## 2. Expected outcome and completion evidence

- **Objective:** a dedicated kit folder where the team's actors live — the
  concrete home of the roster that US-024 fills, explained by a README that
  teaches the concept to anyone who lands there.
- **Completion criterion:** `distribution-kit/devflow/actors/README.md`
  exists; the first line disambiguates `actors/` vs `agents/`; the README
  points to the normative §Actor and references/embeds the canonical
  mermaid; it carries no normative claims of its own.
- **Expected evidence:** the folder tree; the README diff; a spot check
  that the README contains the pointer to §Actor and the disambiguation
  line.
- **Scope:** the folder + README in the kit
  (`distribution-kit/devflow/actors/`).
- **Exclusions:** the roster schema + example and the AITL-enable ADR
  template (US-024); the agent definitions, Coordinator, charters and
  wrappers (US-023); the normative concept text itself (BOLT-001); the
  root `devflow/` governance tree (ADR-004 kit-only).
- **Risks / controls:** the README becoming a second source of truth —
  controlled by the explanatory-only rule (points to §Actor, never citable
  as governed evidence, G28 discipline); `actors/`/`agents/` name
  confusion — controlled by the first-line disambiguation.

---

## 3. Covered acceptance criteria

> Reference the ACs of the parent artifact — never write new ones here
> (§2.4, §2.6).

- `AC-8` (US-022) — **Given** the kit's `devflow/actors/` folder
  (G30-sanctioned by this US), **When** a maintainer inspects it, **Then**
  it contains a README; it is the roster home (schema + example added by
  US-024), disambiguated on its first line from `devflow/agents/`.
- `AC-9` (US-022) — **Given** the `actors/` README, **When** a reader opens
  it, **Then** it teaches the Actor concept (definition, grammar,
  independence layers) with the flow diagram and points to the normative
  definition in Avenga-DevFlow.md — explanatory, never a second source of
  truth; the mermaid's canonical home is the §Actor section (BOLT-001),
  and the README references/embeds it.
