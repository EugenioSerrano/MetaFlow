## 1. Description

Bring the methodology's **describing text** and the **four kit agents** into
agreement with the v5 manifest schema (BOLT-001), so the kit does not contradict
itself about the manifest — the ADR-005 partial-sweep guard applied to the
manifest change.

---

## 2. Expected outcome and completion evidence

- **Objective:** every place that *describes* the manifest matches the v5 schema.
- **Completion criterion:**
  - §3.12 (Manifest Family) describes `checkpoint_approvals[]` (actor + model +
    mode) and `schema_version "5.0"`; every G23 reference agrees.
  - The four kit agent definitions (`CLAUDE.md`, `SKILL.md`,
    `AvengaDevFlow.agent.md`, `AvengaDevFlow.md`) — their "Manifest Family"
    section and any manifest reference — describe the v5 shape, identically
    across the four.
- **Expected evidence (ADR-005 discipline):** a phrase-family sweep shows no
  surviving `hitl_approvals[]` / `schema_version "4.0"` manifest description in
  the kit (outside the allowlist of §5.16 historical references / the separate
  rename US); four-agent whole-body diff = sanctioned divergence only; G-count
  unchanged; `git status` shows only `distribution-kit/`.
- **Scope:** §3.12, the G23 references, and the four agents' manifest sections.
- **Exclusions:** the schema files + templates (BOLT-001); the §5.16 conversion
  path (BOLT-003); the §0 precept rewrite and the HITL→AITL checkpoint rename
  (separate US).
- **Risks / controls:** partial sweep — control: ADR-005 phrase-family sweep over
  the fixed location set; four-agent drift — control: identical edits + sync
  check; accidental checkpoint rename — control: this Bolt touches manifest
  *description* only, the checkpoint identifiers stay as-is.
