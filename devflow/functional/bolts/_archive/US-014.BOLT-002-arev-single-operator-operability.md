# US-014.BOLT-002 — AREV single-operator operability

| Field        | Value |

| **work_category** | feature |
| **Demo / completion evidence** | The kit's AREV machinery is runnable and closable by a single operator with three models: ≥3-model requirement stated, human-arbiter fallback removed, `cancelled` terminal state added to §3.15; kit-only |

---

## 1. Description

Implement **D5** of US-014 in the distributable: make the Adversarial Review
mechanism operable and terminable by a single operator, provided at least
three models are available.

---

## 2. Expected outcome and completion evidence

- **Objective:** in `distribution-kit/`, an AREV requires **≥3 models**
  (Critique, Defense and Verdict each on a distinct model, satisfying G37); the
  single human operator approves the three AREV documents but does **not**
  arbitrate; the **two-model human-arbiter fallback is removed**; and an
  initiated AREV that cannot proceed can be set **`cancelled`**.
- **Completion criterion:**
  - §2.15 / §3.13 state the ≥3-model requirement and that the human approves
    but does not arbitrate; the human-arbiter fallback text is gone.
  - The §3.15 AREV status vocabulary gains `cancelled` as a terminal state —
    **the table is amended before any document uses the value (G39)**.
  - G25/G37 and the four agents' AREV sections are consistent with the above.
- **Expected evidence:** grep/consistency over `distribution-kit/` (≥3-model
  rule present; arbiter fallback absent; `cancelled` in the §3.15 AREV row and
  the AREV templates' status enum); four-agent sync preserved; `git status`
  shows only `distribution-kit/`.
- **Scope:** D5 only — AREV operability.
- **Exclusions:** D1/D2/D3 (US-014.BOLT-001); D7 (US-014.BOLT-003); the root
  tree (ADR-004).
- **Risks / controls:** using `cancelled` before amending the table (control:
  G39 order — table first, verified); four-agent drift (control: identical
  edits + sync check); weakening G37 neutrality (control: the ≥3-model rule
  strengthens, never relaxes, neutrality).

---

## 3. Covered acceptance criteria

- **AC-6** (US-014) — **Given** an AREV, **When** it is initiated, **Then** it
  requires ≥3 models (a single operator running three models is valid); the
  human approves the three documents but does not arbitrate; and an AREV that
  cannot proceed can be set `cancelled`.
