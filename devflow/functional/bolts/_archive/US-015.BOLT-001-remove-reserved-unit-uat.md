# US-015.BOLT-001 — Remove the reserved UNIT/UAT machinery from the kit flow (interim)

| Field        | Value |

---

## 1. Description

Remove the **reserved, non-operational** `HITL-UNIT-Approval` and
`HITL-UAT-Approval` machinery from the active kit flow (the AREV-002 F-03 /
AREV-001 F-06 contradiction), keeping the `tests/uat/` folder **dormant** in
place. Rationale confirmed by the maintainer: the reserved Unit/UAT model does
not reflect real corporate environment/promotion complexity, so it is pulled
now and re-designed properly later (US-015 part b).

---

## 2. Expected outcome and completion evidence

- **Objective:** no active kit text gates on, sequences, or requires
  `HITL-UNIT-Approval` / `HITL-UAT-Approval`; readers see a coherent flow with
  no reserved-checkpoint dead ends.
- **Completion criterion:**
  - The §3.0 checkpoint table no longer lists the UNIT and UAT rows as active
    checkpoints; §3.11 no longer states the "staging UNIT → UAT → production
    UNIT" sequence as an active rule; §3.15 UAT status row and the coverage
    references are removed/neutralized.
  - `GUARDRAILS.md` checkpoint map (UNIT/UAT rows) and G20 (the UNIT/UAT
    sequence rule) removed/neutralized.
  - The four agents' HITL tables no longer list UNIT/UAT as active checkpoints
    (identical across the four).
  - `tests/uat/` is **kept** (README + TEMPLATE-UAT marked **dormant/reserved**,
    pointing at US-015 for future operationalization) — not deleted.
- **Expected evidence:** grep over `distribution-kit/` shows no active
  UNIT/UAT checkpoint in the flow; the `tests/uat/` folder still exists with a
  dormant marker; four-agent sync preserved (G-count 39×5); `git status` shows
  only `distribution-kit/` changed.
- **Scope:** the interim removal (US-015 part a).
- **Exclusions:** part (b) full operationalization of `units/` (future
  Bolt(s), real-world-informed redesign); the identity rules and the other
  checkpoints; the root `devflow/` tree (ADR-004 — next §5.16 migration).
- **Risks / controls:** a dangling UNIT/UAT reference left in the flow
  (control: grep sweep across all locations, AC asserts zero active refs);
  accidental deletion of `tests/uat/` (control: keep the folder, mark dormant —
  explicit AC); four-agent drift (control: identical edits + sync check);
  removing the checkpoint identifiers from the canonical-naming list vs keeping
  them as reserved vocabulary (decided in the SPEC — reserved vs removed).
