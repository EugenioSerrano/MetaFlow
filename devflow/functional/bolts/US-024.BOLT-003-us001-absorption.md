## 1. Description

The deprecated US-001 (team roster, never approved) ACs are **absorbed as
a special case** into the unified roster (US-024): single-maintainer teams
may name **external reviewers**; an **empty roster changes nothing**
(optionality); the roster family **travels with the §5.16 migration**;
roster updates (members join/leave) require **no approval** (living data)
— except an *approver's* charter or authority fields, which re-trigger the
project's AITL-enable ADR review (DISC-002 §5.5, rec #7). The US-001
deprecation record (status: deprecated, doc + INDEX) is closed/confirmed
consistent with the absorption.

## 2. Expected outcome and completion evidence

- **Objective:** the human-only roster's guarantees survive as a special
  case of the actors roster, with a clean deprecation record.
- **Completion criterion:** the roster docs (README/schema notes, US-024)
  state the US-001 special cases (external reviewers, optionality,
  migration travel, living data + the authority re-trigger); the US-001
  doc's deprecation status and the INDEX row are consistent (deprecated,
  absorbed by US-024).
- **Expected evidence:** the absorption text presence; the US-001 doc +
  INDEX row consistency check.
- **Scope:** the roster docs (kit) + the US-001 deprecation record
  (maintenance partition — doc + INDEX).
- **Exclusions:** the schema fields (BOLT-001); the AITL-enable ADR
  template (BOLT-002); the root methodology text (BOLT-002).
- **Risks / controls:** the absorption weakening a guarantee — controlled
  by holding the US-001 ACs verbatim as special cases; the deprecation
