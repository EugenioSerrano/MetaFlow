## 1. Description

Prove the delivered lifecycle end-to-end from the adopter's seat: the
maintainer re-runs the adopter test on a fresh project carrying the
**complete** kit (BOLT-001/002/003/005 all in), exercising
create → install → spawn → delete — and the run is recorded as this
Bolt's evidence. The pilot is the **field verification** of everything the
sibling Bolts shipped as text: the REV-005 baseline (C-01..C-07) should
re-confirm, and the behaviors that were model-diligence or gray-zone last
time (docs-primary navigation, the G07 question) should now be
**contract-driven**.

---

## 2. Expected outcome and completion evidence

- **Objective:** one recorded pilot run on OpenCode, in a fresh scratch
  project (outside this repo) seeded with the current kit:
  1. **Create** — the human asks the MainAgent for a new agent; expected:
     scaffold from template/examples into `agents/squad/<id>/`
     (role-generic, `content_language` charter), actor file +
     `roster.yaml` listing as **executor-only draft**, `agents/INDEX.md`
     row, the wrapper installed to `.opencode/agents/<actor-id>.md`, the
     reload notice given, the commit-is-the-record reminder given — and
     **no Bolt requested** (the scoped G07 honored WITH textual backing:
     the agent can now cite the rule instead of resolving silently).
  2. **Spawn** — after reload, the agent registers (`opencode agent
     list` / ctrl+X — the F-13 notes verified in the field) and produces
     when spawned via the Coordinator.
  3. **Delete** — the human asks for the agent's removal; expected: the
     reference check runs (the contract's enumeration), the wrapper +
     actor file + listing go, the four legs end consistent (squad/,
     INDEX, roster, spawn folder), nothing orphaned.
- **Completion criterion:** the three legs observed with the expected
  behaviors; deviations recorded as findings (a finding does not fail the
  pilot — an unrecorded one does).
- **Expected evidence:** transcript extracts per leg (the human's ask +
  the agent's plan/actions + the G07 stance), the resulting tree before
  delete and after delete, `opencode agent list` output, latency notes
  per leg (REV-005 F-17 — the agent-review/lifecycle economics
  datapoint), and the findings list (empty or not).
- **Scope:** the pilot execution (by the maintainer, in the scratch
  project) + its recording (in this repo: the MEM + a findings annex in
  `agents-data/claude/` if the volume warrants).
- **Exclusions:** fixing anything the pilot finds (each finding routes to
  its own artifact per the REV protocol — the pilot only observes);
  other platforms (a Claude Code repeat may be a later Bolt); the
  headless `opencode run` re-verification beyond recording what the TUI
  run shows.
- **Risks / controls:** the pilot finds a defect — by design: record and
  route, never hotfix in the scratch; the scratch seeded from a stale
  kit — controlled by seeding AFTER the BOLT-005 commit (`93cc94e` or
  later) and recording the seed commit in the MEM.
