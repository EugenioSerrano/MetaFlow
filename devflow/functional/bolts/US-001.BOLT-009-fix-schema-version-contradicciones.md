## 1. Description

Corrige el BUG-004 (aprobado): el diccionario/reglas del transform deben
unificar a `"1.0"` las ocurrencias residuales de `schema_version "5.0"`
(en `23-metrics/README.md:183`, `TEMPLATE-US.md:47` y `TEMPLATE-TC.md:42`)
para que ningún documento del kit se contradiga. **Strict TDD en un único
V-Bounce:** test de reproducción (RED) → fix → GREEN + kit regenerado.

## 2. Expected outcome and completion evidence

- **Objective:** cada documento del kit declara un único valor de
  `schema_version` (`"1.0"`).
- **Completion criterion:** sobre el kit real transformado: cero
  coincidencias de `schema_version "5.0"` / `exactly "5.0"` en
  `23-metrics/README.md`, `TEMPLATE-US.md` y `TEMPLATE-TC.md`.
- **Expected evidence:** kit regenerado + suite completa en verde (RED
  registrado) + evidencia en `transform-reports/`.
- **Scope:** reglas/diccionario de contenido para esos 3 archivos; test de
  reproducción; E2E.
- **Exclusions:** otros defectos; BUG-002/003/005 (Bolts dedicados).
- **Risks / controls:** regresión → la E2E exige `schema_version "1.0"` en
  templates y README de métricas.

## 3. Covered acceptance criteria

> ACs del parent — no se escriben ACs nuevas (§2.4, §2.6). BUG-driven:
> reproduce y corrige BUG-004.

- `BUG-004` — **Given** un kit transformado, **When** se inspeccionan
  23-metrics/README, TEMPLATE-US y TEMPLATE-TC, **Then** no contienen
  `"5.0"` y declaran `"1.0"` (expected result del BUG).
