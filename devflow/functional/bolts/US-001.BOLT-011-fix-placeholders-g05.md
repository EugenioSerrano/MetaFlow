## 1. Description

Corrige el BUG-006 (aprobado): el diccionario/reglas del transform deben
completar las 7 frases truncadas del kit (CLAUDE.md, MetaFlow.agent.md,
.opencode/agents/MetaFlow.md, SKILL.md, README.md, ONBOARDING.md y la regla
G05 de GUARDRAILS.md) nombrando explícitamente el prefijo legacy (p. ej.
"the legacy `AITL-*`/`HITL-*` prefix is invalid"), para que la regla G05 y
el checkpoint map sean legibles. **Strict TDD en un único V-Bounce:** test
de reproducción (RED) → fix → GREEN + kit regenerado.

## 2. Expected outcome and completion evidence

- **Objective:** la regla G05 y las frases del checkpoint map son legibles
  y nombran el prefijo legacy.
- **Completion criterion:** sobre el kit real transformado: cero frases con
  doble espacio vacío (`The  is`, `the legacy  is`, `Use  (the )`) en
  `distribution-kit/`; G05 completa con el prefijo legacy explícito.
- **Expected evidence:** kit regenerado + suite completa en verde (RED
  registrado) + evidencia en `transform-reports/`.
- **Scope:** reglas/diccionario de contenido para las 7 frases; test de
  reproducción; E2E.
- **Exclusions:** otros defectos; el prefijo `CITL-*` se cubre en BOLT-012.
- **Risks / controls:** regresión → la E2E exige cero frases truncadas.

## 3. Covered acceptance criteria

> ACs del parent — no se escriben ACs nuevas (§2.4, §2.6). BUG-driven:

  regla G05 y el checkpoint map, **Then** no hay placeholders vacíos y el
  prefijo legacy está nombrado (expected result del BUG).
