---

## 1. Description

Split the kit's `agents/` family per ADR-013 §3.9: the five shipped role
definitions become **read-only references** in `agents/examples/` (copied,
never referenced by the roster, never edited in place) and the project's
**live agents** get their own home in `agents/squad/` — the folder the
Coordinator writes and the only one the roster's `definition:` pointers
reference.

---

## 2. Expected outcome and completion evidence

- **Objective:** `agents/` ships as: `README.md` (the definition contract +
  the create-your-own guide, moved up from `roles/README.md`) · `INDEX.md`
  (examples shipped + the project's squad, live) · `VERIFICATION.md` (path
  references updated) · `TEMPLATE-new-role/` (moved to the family root) ·
  `examples/` (ex `roles/`: architect, developer, functional-analyst, qa,
  reviewer — with a thin README stating the copy-never-edit rule) ·
  `squad/` (ships empty except its README — the live workspace).
- **Completion criterion:** the family matches ADR-013 §3.9 exactly; the
  `roles/` folder no longer exists; every kit reference to `roles/` paths
  is updated.
- **Expected evidence:** directory listing of `agents/`; the ADR-005
  phrase-family sweep over the kit for `roles/` paths → 0 stale references;
  self-containment grep (0 maintenance IDs); no BOM.
- **Scope:** `distribution-kit/devflow/agents/**` and any kit file
  referencing the old `roles/` paths.
- **Exclusions:** the `actors/` reshape and the enablement-mechanism
  wording (US-024.BOLT-004 — **executes AFTER this Bolt**, so its edits
  land in the post-split paths; this Bolt moves the old governance
  references as-is, BOLT-004 rewrites them); the MainAgent
  lifecycle capability that consumes this shape (US-025 — install from
  `squad/`, create from `examples/`+template); the maintainer-side
  generator/parity in `tools/` (its path config updates when US-025's
  SPEC touches it, or as maintainer tooling maintenance).
- **Risks / controls:** a stale `roles/` path surviving in the kit —
  controlled by the phrase-family sweep (positive coverage, ADR-005);
  confusion between examples and squad — controlled by the two READMEs
  stating the rule (examples: copy, never edit or reference; squad: the
  only roster-referenced home).

## 3. Covered acceptance criteria

- `AC-1` (US-023 rev 3) — the family: `examples/` (read-only references) +
