# US-000.BOLT-011 — Kit self-containment: remove maintainer-repository identifier leaks

| Field        | Value |
|--------------|-------|
| **Parent**   | US-000 (non-functional container) |
| **Type**     | non-functional |
| **work_category** | refactor |
| **service_class** | feature_value |
| **Demo / completion evidence** | Absence sweeps return zero for every leaked identifier family in `distribution-kit/`; an adopter can resolve every referenced ID from the kit alone; G-count 39×5; four-agent parity; root `devflow/` untouched |

---

## 1. Description

Make the distributed methodology (`distribution-kit/`) **self-contained**: a
team that installs only the kit must be able to resolve every identifier the
methodology references, without chasing artifacts that exist solely in the
maintainer repository. Concretely, remove the three leak families evidenced by
REV-004 F-01:

- **(a) `US-015`** — 10 files / 29 occurrences (methodology §3.0, §3.11, §4.7;
  GUARDRAILS G20 + coverage; `devflow/README.md` 2×; `tests/README.md` 4×;
  `tests/uat/{README,INDEX,TEMPLATE-UAT}` 1× each; `analysis/README.md` 3×;
  ONBOARDING 1×; `reports/TEMPLATE-REPORT.html` 11× sample data). All prose
  references are replaced with a version-neutral phrase (e.g. "a redesigned
  model is planned for a future version"); the report's sample IDs are made
  neutral so no example data collides with real repository IDs.
- **(b) `ADR-010`** — 6 citations in the methodology (§3.0, §3.12, §5.16) as
  the normative basis of the actor grammar, while the kit ships no ADRs. The
  outcome: the actor grammar stands on the kit's own text; either the
  citations are dropped (the normative content is already written out in §3.0)
  or the decision is shipped as an in-kit appendix — the SPEC selects the
  mechanism, with the maintainer's preference confirmed at SPEC review. No
  rule content changes: the actor grammar itself remains exactly as defined.
- **(c) CHANGELOG / tools dangling references** — `devflow/README.md`
  cites `CHANGELOG 4.0 "cross-model review round"` (internal history the kit
  does not ship) and `tools/README.md` (a file that does not ship). The first
  is removed; the second is rephrased as an explicit forward reference to the
  tools track ("when the tools track lands") or removed, whichever the SPEC
  judges clearest.

No governance rule, checkpoint, guardrail or schema changes. The deliberate
`HITL-*` legacy mentions (G05, §5.16 migration narrative) are **out of scope**
and stay.

---

## 2. Expected outcome and completion evidence

- **Objective:** every identifier referenced by the kit resolves from the
  kit's own contents; no maintainer-repository ID (`US-015`, `ADR-010`,
  `CHANGELOG 4.0`) and no unshipped file reference (`tools/README.md`)
  survives in the distributable text.
- **Completion criteria:**
  - **`US-015` absence:** zero occurrences of `US-015` in
    `distribution-kit/` prose (the UAT dormant/reserved notes remain, phrased
    without the ID).
  - **`ADR-010` absence:** zero citations of `ADR-010` (or, if the appendix
    route is chosen, the citation resolves to a file that ships with the kit
    — the inventory check below proves it).
  - **No dangling refs:** zero unqualified `CHANGELOG 4.0` citations and zero
    references to files that neither ship nor are explicitly declared as
    forward references.
  - **`adrs/` inventory check:** every `ADR-NNN` cited by the kit exists in
    the kit's own `adrs/` (or is not cited at all).
  - **G-count** = 39 in GUARDRAILS and each of the four agents (39×5) —
    unchanged.
  - **Four-agent body parity** unchanged; `git status` = only
    `distribution-kit/` + root governance records (kit-only, ADR-004).
- **Expected evidence (in the MEM):**
  - Absence sweeps: `US-015` → 0; `ADR-010` → 0 (or resolved in-kit);
    `CHANGELOG 4.0` → 0; `tools/README.md` → 0 or explicitly forward-gated.
  - Link-resolution check over `distribution-kit/` READMEs/INDEXes (the
    REV-004 baseline: 157 links checked, 0 real breaks).
  - G-count 39×5 and four-agent parity outputs.
- **Scope (`distribution-kit/` only):** the 10 files listed in (a)–(c) above.
- **Exclusions:**
  - Root `devflow/` tree (ADR-004) — inherits at the next §5.16 migration.
  - Rule content: actor grammar, AITL/HITL vocabulary, checkpoints, guardrails
    and schemas are untouched.
  - The deliberate legacy `HITL-*` mentions (G05, §5.16) stay.
- **Risks / controls:**
  - Over-broad sweep removes a phrase that carries meaning (e.g. the UAT
    dormant note) → completion criterion keeps the notes, only the ID is
    replaced; the SPEC enumerates each replacement.
  - Removing the `ADR-010` citations could leave the actor grammar
    under-referenced → the normative content is already fully written in §3.0;
    the SPEC verifies the §3.0 text is self-sufficient before any citation
    drops.
  - Sample data change in `TEMPLATE-REPORT.html` could break its layout →
    IDs-only replacement; the SPEC restricts the edit to the ID tokens.
