## 1. Description

Corrige el BUG-007 (aprobado): el diccionario/reglas del transform deben
unificar los nombres de checkpoint al prefijo canónico `CP-*` en
`README.md` (One path y tabla de checkpoints) y `TEMPLATE-SPEC.md` (tabla
de source inventory), eliminando los identificadores `CITL-*` que el propio
GUARDRAILS G05 declara no canónicos. **Strict TDD en un único V-Bounce:**
test de reproducción (RED) → fix → GREEN + kit regenerado.

## 2. Expected outcome and completion evidence

- **Objective:** el kit usa exclusivamente `CP-<CODE>-Approval` para
  nombrar checkpoints.
- **Completion criterion:** sobre el kit real transformado: cero
  coincidencias de `CITL-US`, `CITL-BUG`, `CITL-TC`, `CITL-DISC`,
  `CITL-REV`, `CITL-AREV`, `CITL-ADR` como nombres de checkpoint en
  `distribution-kit/`; README y TEMPLATE-SPEC usan `CP-*`.
- **Expected evidence:** kit regenerado + suite completa en verde (RED
  registrado) + evidencia en `transform-reports/`.
- **Scope:** reglas/diccionario de contenido (frases "origin approved" y
  tablas de checkpoints); test de reproducción; E2E.
- **Exclusions:** otros defectos; el concepto CITL como término (no como
  prefijo de checkpoint) se conserva.
- **Risks / controls:** regresión → la E2E exige cero `CITL-` como
  prefijo de checkpoint.

## 3. Covered acceptance criteria
