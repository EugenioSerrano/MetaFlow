## 1. Description

Corrige el BUG-009 (aprobado): el pipeline debe incluir
`TEMPLATE-REPORT.html` (design reference con ejemplo de datos, según lo
anuncia el README de `42-reports/`) en el kit regenerado — o, si el
template no existe en el input-kit, el diccionario debe ajustar el README
para no anunciar un archivo inexistente. **Strict TDD en un único
V-Bounce:** test de reproducción (RED) → fix → GREEN + kit regenerado.

## 2. Expected outcome and completion evidence

- **Objective:** el kit contiene lo que su documentación anuncia (o la
  documentación no anuncia lo que no está).
- **Completion criterion:** sobre el kit real transformado:
  `distribution-kit/metaflow/42-reports/TEMPLATE-REPORT.html` existe — o el
  README de `42-reports/` no lo declara como presente.
- **Expected evidence:** kit regenerado + suite completa en verde (RED
  registrado) + evidencia en `transform-reports/`.
- **Scope:** reglas/lista de archivos del transform (copiado o
  generación del template) y/o diccionario de contenido del README; test
  de reproducción; E2E.
- **Exclusions:** otros defectos; el generador de reportes (no existe —
  fuera de alcance).
- **Risks / controls:** si el input-kit no trae el template, la decisión de
  incluirlo o ajustar el texto se resuelve con el propietario en el
  V-Bounce (registrado en el MEM).
