## 1. Description

Corrige el BUG-001 (aprobado): las reglas de ruta de numeración (`PN*`)
renombraron los componentes `agents` dentro de las carpetas ocultas de
plataforma (`.github/agents/` → `.github/51-agents/`, `.opencode/agents/` →
`.opencode/51-agents/`), rompiendo el reconocimiento de agentes. El fix
excluye las reglas `PN*` para los componentes bajo carpetas ocultas (primer
componente de ruta que empieza con `.`), conforme a la ADR-003 (la raíz de
plataforma no se numera). **Strict TDD en un único V-Bounce:** test de
reproducción (RED) → fix → GREEN + kit regenerado.

## 2. Expected outcome and completion evidence

- **Objective:** `.github/agents/` y `.opencode/agents/` conservan sus
  nombres en el kit; los agentes de plataforma se reconocen.
- **Completion criterion:** sobre el kit real transformado: existen
  `.github/agents/MetaFlow.agent.md` y `.opencode/agents/MetaFlow.md`; NO
  existen `.github/51-agents/` ni `.opencode/51-agents/`; las carpetas
  internas de `metaflow/` siguen numeradas (51-agents etc.); 0 tokens, 0
  links rotos, 0 sobre-match.
- **Expected evidence:** kit regenerado + suite completa en verde (RED
  registrado) + evidencia en `transform-reports/`.
- **Scope:** engine (`build_plan`: exclusión de PN* bajo carpetas ocultas),
  test de reproducción, fixture/E2E.
- **Exclusions:** otros defectos; X6; migración de gobernanza.
- **Risks / controls:** regresión de la numeración de `metaflow/` → la E2E
  sigue exigiendo las 20 carpetas numeradas.

## 3. Covered acceptance criteria
